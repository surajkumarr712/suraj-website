# Suraj Panda — Portfolio

Personal portfolio website for Suraj Panda, a software engineer focused on cloud platforms, DevOps, AI systems, automation, and data engineering.

## Stack

- Next.js App Router and TypeScript
- Tailwind CSS
- Framer Motion
- `next/font`

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verify a production build

```bash
npm run typecheck
npm run build
```

## Deploy

The project is ready to import and deploy on Vercel with the default Next.js settings.
